Sprites do Claudin.

Poses soltas (um arquivo por pose, .svg ou .png, até ~90 KB, 64x48), valem para o desenho padrão.
Prefira SVG: o app desktop nao desenha PNG embutido. python scripts/png-para-svg.py <pasta> converte pixel art PNG em SVG (o mod carrega .svg antes de .png):
  idle  think  read  code  run  search  ok  err  alert
  Ex.: sprites/code.png. Pose sem arquivo usa o desenho padrão.

Skins (uma pasta por skin, com as mesmas poses):
  sprites/mangue/  sprites/mare/  sprites/malungo/   (do plugin)
  <config>/claudin/sprites/<nome>/                   (as suas)
  Escolha em Ajustes > skin. Pose ausente usa o desenho padrão.

sprites/frota/ guarda as miniaturas da frota (siri, garca, guaiamum, aratu, caranguejinho), uma por tipo de agente; nao e skin.
<config>/claudin/fleet-map.json troca a criatura de um tipo: { "Explore": "aratu" }.
