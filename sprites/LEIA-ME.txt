Sprites do Claudin.

O Claudin e as skins Mangue, Mare e Malungo sao desenhados em codigo (hooks/desenho.ts); nao ha arquivo de pose para elas.

Poses soltas (um arquivo por pose, .svg, 64x48), valem para o desenho padrao:
  idle  think  read  code  run  search  ok  err  alert
  Ex.: sprites/code.svg. Pose sem arquivo usa o desenho padrao.
  PNG so funciona fora do app desktop; python scripts/png-para-svg.py <pasta> converte pixel art PNG em SVG.

Skin propria: <config>/claudin/sprites/<nome>/ com as poses em SVG. Escolha em Ajustes > skin.

As miniaturas da frota (siri, garca, guaiamum, aratu, caranguejinho) tambem sao desenhadas em codigo (hooks/minis-arte.ts).
Para trocar uma: <config>/claudin/sprites/frota/<criatura>.svg (12x12). Nao e skin.
<config>/claudin/fleet-map.json troca a criatura de um tipo: { "Explore": "aratu" }.
