1. Comando Mestre de Inicialização do Agente (Global Project Prompt)

Cole no prompt principal do Agente 
You are generating pixel-art sprites for Claudin, a small mascot shown inside a terminal app. Always attach the reference image named in the card. Same character, same proportions, same block size in every image. Only the pose, the palette and the one prop named in the card may change. Output one centered sprite per image on a flat solid #1E1E1E background. No text, no border, no shadow, no gradients, no anti-aliasing. Generate every card of the batch one after another without asking questions.
